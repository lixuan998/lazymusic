*lazymusic.txt* *lazymusic*  Music in a Neovim floating terminal

Requirements: Neovim 0.10+, macOS or Linux, and an installed lazymusic binary.

make install deploys this plugin and creates/updates the lazy.nvim spec under
~/.config/nvim/lua/plugins/lazymusic.lua (or XDG_CONFIG_HOME/nvim). Existing
differing content is backed up. Set INSTALL_NVIM=0 to install only the binary,
or override NVIM_CONFIG_DIR and NVIM_PLUGIN_DIR for a custom installation.

SETUP                                                       *lazymusic-setup*
>
  require("lazymusic").setup({
    cmd = "lazymusic",          -- executable, not a shell command
    args = {},                 -- e.g. { "--source", "local" }
    width = 0.84,               -- fraction of available columns, or cell count
    height = 0.82,              -- fraction of available rows, or cell count
    border = "rounded",
    keymap = "<leader>mm",      -- false disables the normal-mode mapping
  })
<
The default command is resolved through PATH, then ~/.local/bin/lazymusic.
Arguments are passed directly to the executable without a shell.

COMMANDS                                                 *lazymusic-commands*

:LazyMusic      Open or focus the existing lazymusic terminal.
:LazyMusicHide  Hide its floating window and keep the same TUI process.

<leader>mm opens the terminal in normal mode after setup. In terminal mode,
Esc, Ctrl+h/j/k/l, Ctrl+u/d, H/J/K/L, Ctrl+Enter, Ctrl+= and Ctrl++/- are forwarded
to lazymusic using buffer-local mappings. Resize uses ordinary uppercase
H/J/K/L; Ctrl+Shift+j is no longer a default binding. The terminal must
distinguish control keys for focus/layout shortcuts to work.

Use the TUI's q then q to detach and close the float while music keeps playing;
q then Q stops the selected source's background service. Reopen with <leader>mm
to restore the session. To access Neovim commands from the terminal, press
Ctrl-\ Ctrl-n. Closing the float alone hides the TUI and reuses it next time.

On a nonzero exit, the terminal output remains available for diagnosis.

TUI KEYS                                                   *lazymusic-keys*

? shows only the focused panel plus Global commands; j/k and Ctrl+u/d scroll
help, ? or Esc closes it. Global: H/J/K/L resize, Ctrl+h/j/k/l focus, Space
play/pause, =/- system volume, @ log, +/_ layouts, Ctrl+= reset.

Content: a add menu (a creates in Playlists), y queue, Ctrl+Enter play a song or
entire collection; Play next is in the add menu. r refresh, / filter.
Search: i query, s scope. Queue: Enter play, d remove, D clear,
[/] reorder, f focus the current song and center it when space permits.
Near the queue ends, the view clamps to the first/last page. Queue scrolling
is saved with the session. Global: </> previous/next, Ctrl+< / Ctrl+> seek 10s, x stop,
m playback mode. Queue/Player: r repeat, s shuffle. Player: b quality.
Sound: ,/. cycles Pulse / Wave / Equalizer / Turntable. The turntable embeds
a large circular album cover in the vinyl player, leaving a narrow black rim.
It rotates clockwise while playing, freezes on pause and disappears on stop.
The chassis stays still. The needle rests on the disc while playing/paused
and parks off the disc on stop. The indicator is lit only while playing. Below it, timed lyrics scroll with the
current line centered and highlighted; seeking relocates the active line.
Missing synchronized lyrics show "No Lyrics Available". Apple Music uses
LRCLIB exact metadata matching (title, artist, album and duration), with a
short timeout and a public NetEase Music fallback. The fallback checks the
exact title, all artists and duration, rejecting remixes and covers. Apple
credentials are never sent to either lyric service. LOCAL reads a same-name adjacent .lrc file.
Apple Music loads cover art automatically. LOCAL reads adjacent cover.jpg,
cover.jpeg/png, folder.jpg/png or front.jpg/png (case-insensitive). Missing
covers use a default record. Ghostty/Kitty display a high-resolution photograph
of the entire player. Album artwork uses an antialiased circular center crop,
centered on the platter in the same PNG. Cell rounding and font sizes cannot
offset it from the chassis.
The photographic asset is embedded in the binary. Direct image transfer also
works across SSH/WSL. Resize and normal/Zen changes update placement without
re-uploading the current frame. Rotation edits the disc region when supported;
older terminals receive complete images. Only one frame is prepared/sent at a
time, so slow connections do not queue historical frames. Pause and hidden
views stop the animation clock. Unsupported terminals approximate the whole image.
Unsupported terminals fall back to color half-block images. Set
LAZYMUSIC_IMAGE_DISABLE=1 to force this fallback. tmux/zellij default to it.
Native images in the Nvim float require Nvim 0.12+, termguicolors, and the
bundled image relay (updated by make install). Older Nvim uses the fallback.
The relay handles only buffer-local direct image commands and cleans up its
own images when the music terminal exits; it cannot access arbitrary files.
Cover requests are cancellable and cached in memory, never in the session.
The header is framed; Player expands vertically with separate metadata,
progress and status rows, using a solid half-height progress bar. Small terminals use a compact layout.
Sound EQ: h/l band, j/k gain, e bypass, r flat, p preset.
Content p/P picks a song or collection. Queue p/P picks a song when nothing is
held; then p places after the cursor song, P places before it. Esc cancels.
Queue pickups move; Content pickups copy into Queue. Albums/playlists expand
all track pages; artists expand all their albums and tracks in source order.
The picked item is marked with a diamond and a status line. Collection reads
are asynchronous and cancellable. Placement is a single guarded queue edit,
preserves playback, and waits for its reply before allowing another placement.
Content/Queue: u undoes the last successful pick/place; u again redoes it.
It toggles until the next successful placement replaces the record. Collections
undo as a batch. Canceled, failed and unchanged placements keep the record.
Undo/redo survives session restoration and never rewinds surviving playback.
Removing the playing inserted song stops it; redo stays paused. Tail appends
(including radio refill) preserve history; other queue edits invalidate it.
o/c opens album/artist links or credits in Content, Queue and Player.
Login is available through Navigation or :login. Text fields keep letters
as text; Esc/Ctrl+c cancels. The plugin has no separate music keymap.
In Apple sign-in, Enter/l starts authorization. The full manual URL appears at
the top when ready; y requests clipboard copy using OSC 52 (Nvim's configured
clipboard provider). You can also select the displayed URL manually. WSL users
can open it in their Windows browser. Preparation/download and safe failure
reasons stay in Login. Older Linux C++ runtimes are handled with verified,
private compatibility libraries used only by the authorization helper.
Navigation is immediate. Holding h/j/k/l repeats within the focused panel.
There are no double-tap bindings. Ctrl+< / Ctrl+> (Ctrl+Shift+comma/period)
seeks backward/forward 10 seconds from any panel.

Pulse and Wave use a frontend-only 30 FPS animation clock. Pulse has gradient
bars, decaying peaks and reflections; Wave draws layered curves with braille
sub-cell resolution. Pause/resume and view changes ease smoothly. Settled or
hidden visualizations stop scheduling frames. These are decorative animations,
not a live audio spectrum. Use ,/. in Navigation/Sound or Ctrl+- for Zen.
In Zen, ,/. cycles Pulse / Wave / Turntable while Equalizer and Player remain
visible. h/l and j/k still adjust the EQ. There is no duplicate EQ/wave slot.

Apple Music: add songs/albums to the library, create playlists, and add songs
to editable playlists. Cloud deletion is unavailable in Apple's public API;
d on a library item explains this limit. No local files are deleted.

APPLE MUSIC navigation includes Home, New and Radio; LOCAL omits these pages.
Home keeps every category/resource returned by the recommendations API,
including stations and unsupported resource types. Available categories vary
by account, region and time. New/Radio use structured content from Apple's
public regional pages, without sending account authorization or requiring a
browser. Use ,/. in Content to switch categories and View all to open full
sections where available. Categories and navigation restore with the session.
Track-based personal, discovery, artist and genre stations play natively on
macOS/Linux: Enter or Ctrl+Enter tunes the station, and the background service
refills upcoming songs automatically. The player shows the station and current
song. Pause, resume, seek, next/previous, EQ and background sessions use the
usual controls. Cold restore stays paused and retains the station context.
Replacing/clearing the queue ends station mode. An endless station cannot be
expanded with y/p into a fixed collection; add individual songs from Queue.
Radio episodes resolve as finite stream entries: Enter plays, y queues, and
p/P picks/places them. Native CBCS playback, seeking and paused restoration
have been verified on macOS/Linux. Live media-window refresh has regression
coverage, but real live radio is not verified with the current account/region
(the media endpoint returns 404). Videos remain visible with playback limits.
Public page format changes or regional redirects report an error instead of
presenting another page. The plugin shares the TUI's station controls.
